# SendLiberty - Seamless Email Relay API

SendLiberty is a robust, developer-centric email relay API designed to simplify transactional and batch email sending. Leveraging Gmail OAuth2 and custom SMTP configurations, it eliminates the complexities of direct SMTP integration, allowing developers to send emails securely and efficiently with a simple API key.

## Features

*   **Gmail OAuth2 Integration**: Securely connect your Gmail or Google Workspace accounts without sharing passwords.
*   **Custom SMTP Support**: Configure your preferred SMTP provider (e.g., SendGrid, Mailgun, Outlook) for flexible email delivery.
*   **API Key Authentication**: Secure access to the API using unique, revocable API keys.
*   **Transactional Email Sending**: Send individual emails for critical communications like welcome messages, password resets, and notifications.
*   **Batch Email Sending**: Efficiently send bulk emails for newsletters and marketing campaigns with configurable batch sizes and delays.
*   **Scheduled Email Delivery**: Plan and schedule emails to be sent at specific future times no need to add cron jobs to your applications for sending mails.
*   **Comprehensive Email Logging**: Track the status and details of all sent and failed emails.
*   **Pay-as-you-go Credit System**: Purchase credits as needed, with no subscriptions or expiration dates.
*   **Developer-Friendly SDK**: Integrate easily into your applications using the provided SDK (currently inferred, but a separate package is mentioned in `package.json`).
